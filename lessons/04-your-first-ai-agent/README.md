# Lesson 4 · Your first AI agent

▶ [Watch this lesson](https://youtu.be/nRxDPfsSjk0?t=519) (starts at 8:39)

## Goal

Lesson four. Your first AI agent.

## In this lesson

Create an **OpenAI** credential with your API key, then import [`app/workflows/02-assistant.json`](../../app/workflows/02-assistant.json): Chat Trigger → AI Agent + OpenAI Chat Model (`gpt-6-luna`) + Simple Memory. System message: *You are a friendly, concise assistant. Answer in two or three sentences.* Select your credential in the model node and click **Open chat**.

## Recap

So: a chat trigger plus an AI agent gives you an assistant. The model connects through a credential. And memory keeps the conversation. But it still can't do anything. Let's give it tools.
